* Introduction
orgnote.el is a package for synchronizing your org-roam notes, or just org files with property id from emacs with an external application - [[https://org-note.com][orgnote]] and vice versa.
For correct usage you need to have API and activation key

* Install
** Install dependencies
1. Install [[https://docs.npmjs.com/downloading-and-installing-node-js-and-npm/][Node.js (includes npm)]] or [[https://bun.sh/][bun]]
2. Install orgnote-cli
   Run =M-x orgnote-install-dependencies=
   or =npm install -g orgnote-cli=
3. Install required Emacs packages: ~tomlparse~ and ~websocket~

** Doom
~package.el~
#+BEGIN_SRC emacs-lisp
(package! orgnote
  :recipe (:host github :repo "artawower/orgnote.el"))
#+END_SRC
~config.el~

#+BEGIN_SRC emacs-lisp
(use-package! orgnote
  :defer t
  :config
  (orgnote-autosync-global-mode 1))
#+END_SRC
** Straight
#+BEGIN_SRC emacs-lisp
(use-package orgnote
  :ensure t
  :config
  (orgnote-autosync-global-mode 1))

** For development version
#+BEGIN_SRC emacs-lisp :results silent
(use-package orgnote
  :ensure (:host github :repo "Artawower/orgnote.el" :branch "dev")
  :config
  (orgnote-autosync-global-mode 1))
#+END_SRC
* Usage
** Auto-sync modes
~orgnote-autosync-mode~ - local minor mode that enables auto-sync on save for the current buffer. Only activates for org files within configured ~rootFolder~ directories.

~orgnote-autosync-global-mode~ - global mode that enables ~orgnote-autosync-mode~ for all qualifying org files. Also establishes WebSocket connections for real-time sync notifications from the server.

** Commands
- ~orgnote-sync~ - manually trigger sync for the current account
- ~orgnote-force-sync~ - force sync, clearing local cache first
- ~orgnote-open-configuration~ - open config file for editing
- ~orgnote-share-current-buffer~ - share current org buffer via OrgNote preview
- ~orgnote-share-region~ - share selected region via OrgNote preview

** Configuration
Read more about CLI tool [[https://github.com/Artawower/orgnote-cli][here]]

Example ~config.toml~:
#+BEGIN_SRC toml
[[accounts]]
name = "personal"
remoteAddress = "https://dev.org-note.com"
clientAddress = "https://dev.org-note.com"
token = "your-api-token"
rootFolder = "~/org-roam"
logPath = "~/.cache/orgnote.log"
#+END_SRC

** Required fields:
- ~name~ - account identifier
- ~remoteAddress~ - backend API URL
- ~token~ - API token from OrgNote settings
- ~rootFolder~ - local directory to sync (required for auto-sync)

** Optional fields:
- ~clientAddress~ - frontend URL for preview sharing
- ~logPath~ - path to log file

** TOML parsing setup
TOML parsing uses ~tomlparse~ (tree-sitter). Requires Emacs 29.1+ and TOML grammar:
#+BEGIN_SRC emacs-lisp
(add-to-list
 'treesit-language-source-alist
 '(toml "https://github.com/tree-sitter-grammars/tree-sitter-toml"))
(unless (treesit-language-available-p 'toml)
  (treesit-install-language-grammar 'toml))
#+END_SRC
